Add `Segmented` control — a single-select toggle with a clearly visible active state, filling the gap where `ButtonGroup`'s selected style (`bg-bg-secondary`) is too faint for settings toggles. Built on React Aria `ToggleButtonGroup`. Two variants: `surface` (default, raised `bg-bg` pill on a gray track, iOS-style) and `brand` (active = `bg-primary`). Exports `Segmented` + `SegmentedItem`; sizes `sm`/`md`.
