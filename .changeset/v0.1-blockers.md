Add v0.1 blocker components: Form, Modal, DateRangePicker, Carousel.

**`Form` / `HookForm` / `FormField` / `useFormFieldContext`**
`react-hook-form` wrapper over React Aria Form. `HookForm` provides `FormProvider` context. `FormField` extends `UseControllerProps` (includes `rules`, `defaultValue`, `control`, `name`). `useFormFieldContext` exposes field `id`, `name`, and `control` to deep children.

**`ModalOverlay` / `Modal` / `Dialog` / `ModalHeader` / `ModalBody` / `ModalFooter`**
React Aria `ModalOverlay` + `Modal` + `Dialog` primitives. Animated overlay with `backdrop-blur-sm`. Five sizes: `sm` / `md` / `lg` / `xl` / `full`. Closes on overlay click or Escape. Use controlled state (`isOpen`/`onOpenChange` on `ModalOverlay`) — `DialogTrigger` requires an RAC-aware trigger child which `Button` is not.

**`CalendarCell`** (shared)
Extracted from `date-picker.tsx`; auto-detects single vs range mode via `RangeCalendarContext`. Used internally by both `DatePicker` and `DateRangePicker`. Also exported from the package for custom calendar builds.

**`DateRangePicker`**
React Aria `RangeCalendar`-backed date range picker. Preset sidebar (Today, Yesterday, This week/month/year and last equivalents). Single-month calendar. Apply/Cancel footer. Controlled (`value`/`onApply`) and uncontrolled (`defaultValue`) modes. Requires `@internationalized/date` as a peer for preset arithmetic.

**`Carousel`** (A8 compound namespace exception)
Embla-carousel-react backed slider. Compound namespace: `Carousel.Root`, `.Content`, `.Item`, `.PrevTrigger`, `.NextTrigger`, `.IndicatorGroup`, `.Indicator`. `opts` prop forwarded to Embla. Trigger and Indicator components accept `children` as render-prop (receives `{ canScrollPrev, canScrollNext }` / `{ isSelected }`), element, or `asChild` pattern.
