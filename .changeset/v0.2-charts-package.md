Initial release of `@mvp-ui/charts` package.

Charts are a separate package (`pnpm add @mvp-ui/charts`) to avoid adding Recharts to the main `@mvp-ui/ui` bundle.

Components:
- **BarChart** — stacked or grouped bar charts. Multi-series, custom colors, axis labels, tooltip.
- **LineChart** — area / line charts with gradient fills. Dashed lines, multiple series, active-dot animation.
- **PieChart** — donut or solid pie. Per-item colors, configurable legend placement.
- **ProgressCircle** — radial progress ring. Four sizes, optional title/subtitle labels, custom arc and track colors.

Shared utilities:
- `ChartTooltipContent`, `ChartLegendContent`, `ChartActiveDot` — composable chart sub-components.
- `CHART_COLORS` — default brand-scale CSS-var palette array.
- `selectEvenlySpacedItems` — axis tick distribution utility.

All charts are themed via CSS custom properties (`--color-*`) from `@mvp-ui/tokens`. Dark mode is supported automatically when tokens flip.
