Add v0.2 components: Combobox, MultiSelect, TagSelect, Table, FileUpload, Toast, CommandMenu, SidebarNav.

- **Combobox** (`ComboBox`) — searchable combobox via React Aria. Optional shortcut kbd, icon, label, hint, tooltip.
- **MultiSelect** — multi-selection dropdown with Autocomplete filter, select-all, reset footer, badge count.
- **TagSelect** — tag-chip selection with removable chips in the trigger.
- **Table** (`Table`, `TableCard`) — React Aria table with sorting, row selection, size variants, card wrapper.
- **FileUpload** (`FileUpload`) — drag-drop drop zone, progress bar list item, fill-behind-row list item. MIME + size filtering.
- **Toast** (`Toaster`, `toast`) — Sonner wrapper with design token theming. All toast variants (success, error, warning, info, promise, action).
- **CommandMenu** — keyboard-accessible command palette via AriaComboBox + ModalOverlay. Grouped items, shortcuts, disabled items.
- **SidebarNav** (`SidebarNavSimple`, `SidebarNavDualTier`, `SidebarNavSectionDividers`, `SidebarNavSectionsSubheadings`, `SidebarNavSlim`) — five application sidebar layout variants using CSS width transitions.
